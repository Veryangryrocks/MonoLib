A library for MonoGame.

Implements:
- IO
  * Cached Content loading
  * Cached Json loading
  * Unity-like input binding
- Graphics
  * A RenderGraph with depth first, material second batching--controlled by the GraphicsManager
    + Blit
    + Composite
    + Duplicate
    + Material
    + Present
    + Raster
  * Fullscreen functionality
- Util
  * Degrees and Radians
